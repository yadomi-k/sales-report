# 売上レポート（試作品）

Salesforceの商談・商談分割・ユーザのデータから、**個人・チーム・課・部ごとの売上／利益の実績と目標**を
表とグラフで表示し、Excel（書式付き）・CSVで出力するWebアプリです。

- Salesforceのデータは**読み取るだけ**です。商談オブジェクトの変更、Apex・LWC・Visualforceは使いません。
- CaseShelfとは別のアプリです。ログインの仕組みはCaseShelfと同じ「Salesforceでログイン」（専用の接続アプリケーション + PKCE。サーバー不要）です。
- ログインせずに「デモデータで試す」で画面を確認できます（ダミーデータ。実在の会社・人物とは無関係）。

## 1. 動かし方

ビルド不要です（CaseShelfと同じく、React・Chart.js・ExcelJSをCDNから読み込みます）。

```bash
cd <このREADMEがあるフォルダ>
python3 -m http.server 8790
```

ブラウザで `http://localhost:8790` を開きます。

## 2. 集計の考え方

| 項目 | 計算方法 |
|---|---|
| 個人売上 | **商談分割の金額**（SplitAmount）を積み上げ |
| 個人利益 | **商談分割の利益額**（SplitProfit__c）を積み上げ |
| 対象の商談 | レコードタイプ「実績」の商談 |
| 月 | 商談の **売上日**（EstimatedSaleDate__c）の月（年度は1月始まり） |
| 部・課・チーム | **商談分割の所有者**の、ユーザの部（Department__c）・課（Division__c）・チーム（Team__c）（※現在の所属） |
| 目標 | レコードタイプ【個人目標】かつステージ「目標」の商談の **売り上げ目標**（SalesGoal__c）・**目標利益額**（TargetProfit__c）。部署は目標の **所有者** で判定し、部・課・チームの目標は所有者ごとの目標の合計 |
| 受注確度 | ステージが 受注・制作進行・請求・完了 →「受注」。タネ・案件詳細入手・着手承認済み・見積提出済み → 検索用受注確度（PossibilityForSearch__c）の値で「高・中・低」。それ以外のステージ（失注など）は集計せず、件数を画面に表示 |

表の行（今のVisualforceの表と同じ並び）

| 確度 | 行 | 売上の列 | 利益の列 |
|---|---|---|---|
| 確度 | 目標 | 目標売上金額 | 目標利益金額 |
| 受注 | 金額 / 達成率 / 件数・利益率 | 受注の金額 | 受注の利益 |
| 高・中・低 | 積上金額 / 積上達成率 / 件数・利益率 | 受注からその確度までの合計 | 同左 |

- 達成率 = 金額 ÷ 目標。目標に届いていない金額は赤字で表示します。
- 件数 = 商談の件数（同じ商談が複数人に分割されていても、同じ表の中では1件と数えます）。
- 列は「月 → 四半期合計 → 上期計・下期計 → 年間計（期間計）」の順です。

## 3. 画面でできること

- **検索条件**：期間（売上日の月）、部・課・チーム・担当者、受注確度、案件ステージ、コンペ区分、
  分割の金額の範囲、取引先名・商談名（部分一致）
- **表示単位**：合計のみ／部ごと／課ごと／チームごと／担当者ごと（並び順：名前・目標・受注金額）
- **表示切り替え**：表とグラフ／表／グラフ／明細（商談分割の一覧）。グラフは売上・利益を切り替え可能
- **出力**：Excel（今の表と同じ色・書式。「明細」シート付き）、CSV
- **検索条件の保存**：名前を付けて保存（※試作品では、このブラウザにだけ保存されます）

## 5. ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 入口。ライブラリとアプリのファイルを読み込む |
| `src/config.js` | 設定（Salesforceの接続先、項目のAPI参照名） |
| `src/sso.js` | Salesforceでログイン（CaseShelfと同じ方式）、REST APIの呼び出し |
| `src/sfdata.js` | Salesforceからユーザ・商談分割・目標を読み取る |
| `src/demo.js` | デモデータ |
| `src/aggregate.js` | 集計（表・グラフ・出力で共通） |
| `src/export.js` | Excel・CSV出力 |
| `src/app.jsx` | 画面 |
| `styles.css` | 見た目 |
