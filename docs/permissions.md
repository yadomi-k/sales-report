# VISORA 閲覧権限の設定手順書

## 1. 目的

| 見る人 | Salesタブ（営業の数字） | Creativeタブ（クリエイティブ部の数字） |
|---|---|---|
| 営業の人 | 見られる | **見られない** |
| クリエイティブ部の人 | 見られる | 見られる |
| 製作課など、上記以外の人 | （必要に応じて 5. で制限） | **見られない** |

## 2. 仕組み（なぜSalesforceの設定で守れるのか）

VISORAは、ログインした人の**Salesforceの権限のまま**データを読み取ります。VISORAが独自に権限を持っているわけではありません。

- Creativeタブの数字は、プロジェクト管理（`Creative_Achievements__c`）の**金額の項目**から読み取ります。
- ログインした人が、Salesforceでこの金額の項目を参照できない場合、VISORAは**Creativeタブ自体を表示しません**。
- 画面で隠しているだけではなく、Salesforceがデータを返さないため、ブラウザの開発者ツールなどを使っても数字は取り出せません。
- 同じ設定で、Salesforceのレポート・ダッシュボード・リストビューでもその金額は見えなくなります。

つまり、**「金額の項目を、クリエイティブ部の人だけが参照できる」ようにSalesforceを設定すれば、VISORAでもSalesforce本体でも守られます。**

## 3. 推奨する設定：項目レベルセキュリティ＋権限セット

オブジェクト（プロジェクト管理）そのものは営業の人も参照できるまま残し、**金額の項目だけ**を隠します。

> オブジェクトごと参照できなくすると、CaseShelfの「デザイン担当者の自動入力」（商談 → 商談商品 → プロジェクト管理 → 所有者 をたどる機能）が営業の人で動かなくなるためです。

### 手順 3-1. 今の状態を確認する

1. **設定 → オブジェクトマネージャ → プロジェクト管理（Creative_Achievements__c）→ 項目とリレーション**
2. 金額の項目（例：金額、目標金額）を開き、**「項目レベルセキュリティを設定」**を押す
3. どのプロファイルに「参照可能」が付いているかを控える（営業のプロファイルに付いていれば、それが外す対象）

対象の項目（VISORAが読むもの。API参照名は `src/config.js` の `creative` を参照）

| 項目 | 隠す対象 |
|---|---|
| 金額（`amountField`） | 必ず |
| 目標金額（`targetField`） | 必ず |
| コンペ結果（`resultField`） | 必要に応じて（件数だけなので、隠さなくても金額は分からない） |
| そのほか売上・原価・利益に関する項目 | 必ず（VISORAが読まなくても、Salesforce本体で見えてしまうため） |

### 手順 3-2. 権限セット「VISORA Creative閲覧」を作る

1. **設定 → 権限セット → 新規**
   - 表示ラベル：`VISORA Creative閲覧`
   - API参照名：`VISORA_Creative_Viewer`
   - ライセンス：（なし）のままでよい
2. 作成した権限セットの **「オブジェクト設定」→ プロジェクト管理 → 編集**
   - オブジェクト権限：**参照**にチェック（クリエイティブ部の全員の数字を見るため、必要なら**すべて参照**にもチェック。下の 3-4 参照）
   - 項目権限：手順 3-1 の金額の項目すべてに **参照アクセス権** をチェック
3. 保存する

### 手順 3-3. 営業などのプロファイルから金額の項目を外す

1. 手順 3-1 の画面（項目レベルセキュリティ）で、クリエイティブ部**以外**のプロファイルの「参照可能」を外す
   - システム管理者のプロファイルは残してよい
   - クリエイティブ部と営業が同じプロファイルを使っている場合は、ここでそのプロファイルから外し、クリエイティブ部の人には 3-2 の権限セットで付け直す
2. 金額の項目ごとに繰り返す

### 手順 3-4. 共有設定（誰のレコードまで見られるか）

1. **設定 → セキュリティ → 共有設定** で、プロジェクト管理の「組織の共有設定」を確認する
2. 「非公開」の場合、クリエイティブ部の人は他の人のプロジェクトを見られず、ダッシュボードの合計が合わなくなる
   - 権限セット 3-2 で **「すべて参照」** を付ける、または
   - 共有ルールで「クリエイティブ部のロール」に全件の参照を共有する

### 手順 3-5. クリエイティブ部の人に権限セットを付ける

1. **設定 → 権限セット → VISORA Creative閲覧 → 割り当ての管理 → 割り当てを追加**
2. クリエイティブ部のメンバーを選んで割り当てる
3. 異動・入社のときに、ここでの付け外しを忘れないようにする（運用ルールに入れておく）

## 4. 確認する

| 確認すること | 方法 | 期待する結果 |
|---|---|---|
| 営業の人に見えない | 営業の人のアカウントでVISORAにログイン（またはシステム管理者が「ログインユーザーとしてログイン」で確認） | 上部に **Salesタブしか出ない** |
| クリエイティブ部の人に見える | クリエイティブ部の人のアカウントでログイン | **SalesタブとCreativeタブ**が出て、数字が表示される |
| Salesforce本体でも見えない | 営業の人でプロジェクト管理のレコード・レポートを開く | 金額の項目が表示されない |

> 設定を変えた後、すでにVISORAを開いている人は、一度ログアウトしてログインし直すと反映されます。

## 5. （必要に応じて）VISORAにログインできる人自体を限定する

製作課など、営業の数字も見せたくない人がいる場合は、VISORAの接続アプリケーションを「許可した人だけ」が使えるようにします。

1. **設定 → アプリケーションマネージャ → VISORA（売上レポート）の接続アプリケーション →「Manage（管理）」→「ポリシーを編集」**
2. **許可されているユーザー**：「管理者が承認したユーザーは事前承認済み」に変更して保存
3. 権限セット `VISORA利用者`（新規作成。中身は空でよい）を作り、その接続アプリケーションを **「割り当てられた接続アプリケーション」** に追加
4. VISORAを使ってよい人（営業・クリエイティブ部）に `VISORA利用者` を割り当てる

これで、割り当てのない人はVISORAにログインできなくなります。

> ただし、Salesforce本体で商談を参照できる人は、Salesforceの画面からは商談の数字を見られます。営業の数字そのものを見せたくない場合は、商談の共有設定・項目レベルセキュリティも合わせて見直してください。

## 6. プランニング課の数字について

Creativeタブのプランニング課は、プロジェクト管理に加えて**商談分割（受注）と商談の【個人目標】**も読み取ります。
そのため、Creativeタブを使うクリエイティブ部の人は、Salesタブと同じく**商談・商談分割を参照できる**必要があります。
（商談の数字は営業も見られる数字なので、営業の人に見えても問題ない前提です）

## 7. 注意点

- VISORAはデータを**読むだけ**で、書き換えはしません。
- 権限の判定はすべてSalesforce側で行われます。VISORAの設定ファイル（`src/config.js`）を書き換えても、権限のない数字が見えるようにはなりません。
- 権限の変更は、Salesforceのシステム管理者が行ってください。
