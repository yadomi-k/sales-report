# 変更履歴（週次）のための設定手順書

VISORAの Sales →「変更履歴（週次）」は、商談の **項目履歴**（Salesforceの標準機能）から、
「売上金額」「案件ステージ」の変更（いつ・誰が・何から何に変えたか）を読み取ります。

## 1. 商談の項目履歴管理をオンにする

**設定 → オブジェクトマネージャ → 商談 → 項目とリレーション →「項目履歴管理の設定」**

1. 「商談の履歴の有効化」がオンになっていることを確認
2. 次の2つの項目にチェックを入れて保存
   - **案件ステージ**（`StageName`）
   - **売上金額**（`OrderEstimate__c`。`src/config.js` の `opportunity.salesAmount` に設定済み）

> 項目履歴管理は1オブジェクトにつき最大20項目まで。すでに使っている項目がある場合は、残りの枠を確認してください。
> 項目の追加や変更ではなく「設定」なので、商談オブジェクトの項目や画面には影響しません。

## 2. 注意点

- **さかのぼれません**：履歴は、オンにした時点より後の変更から記録されます。
  すでにオンになっていれば、その時点からの履歴が使えます。
- **保存期間**：Salesforceの項目履歴は、標準で **18か月** 保存されます（APIでは24か月まで）。週次の報告には十分です。
- **見える範囲**：ログインした人が参照できる商談の履歴だけが表示されます。
- **担当者**：VISORAでは **商談の所有者**（今の所有者）を担当者として集計します。実際に編集した人は「編集した人」の列に出ます。
- **部署**：担当者のユーザの **今の** 本部・部・課・チームで絞り込みます。Salesタブと同じく、対象の部署（`user.targetDepts`）の商談だけが出ます。

## 3. 上部の集計（情報・受注・失注）の考え方

期間の **始まりの時点** と **終わりの時点** の、商談ごとのステージと売上金額を比べています。

| 例 | 情報 | 受注 | 失注 |
|---|---|---|---|
| 100万円の商談が「見積提出済み → 受注」 | ▲100万 | +100万 | |
| 受注中の商談の売上金額が 80万 → 100万 | | +20万 | |
| 50万円の商談が「着手承認済み → 失注」 | ▲50万 | | **▲50万**（失注が増える＝売上が減るので▲で表示） |

区分のステージは `src/config.js` の `history.groups` で変えられます。

## 4. 確認

VISORA → Sales →「変更履歴（週次）」を開き、直近1週間の変更が出ることを確認します。
「商談の変更履歴を読めませんでした」と出る場合は、1 の設定と、売上金額のAPI参照名を確認してください。
